# Hướng dẫn Admin V16

1. Mở `https://thanh-hang-birthday.vercel.app/admin`.
2. Đăng nhập bằng username và mật khẩu bạn đã thiết lập trên Vercel. Không lưu mật khẩu trực tiếp trong source.
3. Vào **02 / OUR JOURNEYS** để thêm/sửa/xóa/ẩn hiện/sắp xếp chuyến đi.
4. Vào **Album**, **Lời chúc**, **Bình luận** để quản lý dữ liệu; khách gửi lời chúc/bình luận được hiển thị ngay. Không còn bước chờ duyệt.
5. Với nội dung không phù hợp, chọn **Ẩn** (có thể khôi phục bằng **Hiện**) hoặc **Xóa**.
6. Vào **Nội dung & nhạc** để đổi lời chúc chủ trang và URL nhạc.
7. Vào **Sao lưu** để tải dữ liệu JSON; lưu tại nơi riêng tư.

Xem `HUONG_DAN_CHINH_SUA.md` và `README_DEPLOY.md` để chỉnh sửa source, kết nối GitHub và các biến môi trường.
